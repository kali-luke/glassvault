# The Glass Vault

A daily heist puzzle. Five locks, one vault, the same puzzles for everyone each day.

Play it at https://kali-luke.github.io/glassvault/

All of the game is in `index.html`. `sw.js` and `manifest.webmanifest` let it install on a phone and open with no signal. Add `?tools` to the address to show the prototype tools.
